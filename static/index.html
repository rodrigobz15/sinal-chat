Frequently Asked Questions

How does interest matching work?+
You type in any topics you want (e.g. games, music) and we try to connect you with someone who listed something similar. If nobody compatible is around, you're matched with the next available person anyway — nobody waits forever.
Do I need to sign up?+
No. Just choose text or video and click start. No personal data is requested.
Does it work on mobile?+
Yes, it works right in your phone's browser, no install needed.
Is it safe to talk to strangers here?+
This is still a personal project under construction, with no automated moderation behind it. Use common sense: never share personal data, and leave the conversation (the "next" button) if something seems off.
